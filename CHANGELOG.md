# Changelog

## 1.1.0 - 2026-11-17

### Added

- Optional Mod Menu 17.0.1 integration.
- In-game keybind editor with rebind and reset.
- Human Mode presentation for smooth aiming and click delay.
- Wordmark logo for the README and release.

### Changed

- Config screens return to Mod Menu when opened from the mod list.
- Default keybinds remain F10 and F11.

## 1.0.0 - 2026-11-17

### Added

- Standalone Fabric mod for Minecraft 1.21.11.
- Litematica and Sponge schematic loading, including zip archives.
- Native Minecraft GUI with `F10` open and `F11` toggle keybinds.
- Automatic target calculation and placement with the player's inventory.
- Temporary scaffold blocks and optional cleanup.
- Optional obstruction breaking and multi-round retries.
- Optional singleplayer command fallback.
- Smooth aiming, click delay and stuck detection.
- Persistent settings in `config/champ-auto-build.json`.
- Mod icon, screenshot, README, MIT license and security notes.
- Release jar and sources jar.
